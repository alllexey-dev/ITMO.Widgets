# Wi-Fi

## Что получает пользователь

Строка «Wi-Fi» на экране «ИСУ» в «Профиле» открывает шторку с сетью ITMO-Corp, логином и паролем от неё. Пароль скрыт точками,
пока его не показать; логин и пароль можно скопировать. На Android кнопка «Подключиться» сохраняет сеть на телефоне:

- на Android 11 и новее — системным окном «Сохранить сеть?»;
- на старых Android и там, где система отказала, приложение копирует пароль и открывает настройки Wi-Fi.

На iPhone кнопки подключения нет: пароль копируется и вставляется в настройках Wi-Fi вручную.

Ниже есть настройки для ручного подключения: метод EAP — PEAP, этап 2 — MSCHAPV2, сертификат — системный, домен —
wifi.it.itmo.ru.

## Откуда данные

Пароль от Wi-Fi выдаёт ИСУ, на странице «Настройки Wi-Fi». Телефон заходит туда сам — через вход в ITMO.ID, который
уже есть на телефоне, — и только читает страницу. Сервер ITMO.Widgets в этом не участвует и пароля не видит.

## Правила

- Логин и пароль не сохраняются на телефоне: при каждом открытии шторки приложение заново читает их из ИСУ и
  показывает загрузку. Без сети или при ошибке ИСУ шторка показывает ошибку и кнопку повтора, а не старый пароль.
- Новый пароль приложение не выпускает: если пароля ещё нет, шторка предлагает открыть ИСУ и получить его там.
- Если на телефоне нет входа в ITMO.ID (например, вход был по refresh-токену), ИСУ не открывается без пароля — шторка
  предлагает «Войти через ITMO.ID». Это тот же вход, что для БАРС: после него приложение снова читает ИСУ.
- Если ранняя бета 2.3 успела сохранить пароль на телефоне, приложение стирает его при первом открытии шторки или
  при выходе из аккаунта.
- В демо-режиме показываются вымышленные логин и пароль, ИСУ не запрашивается.
