# Ссылки и чаты предметов

## Что получает пользователь

На странице предмета в зачётке — блок «Ссылки»:

- свои ссылки: таблица баллов, очередь на сдачу, материалы, задания, записи
  лекций, конспекты, к экзамену, другое;
- чаты предмета — отдельным списком;
- ссылки однокурсников, которыми поделились с вашим потоком или со всеми;
- «С прошлых лет» — проверенные общие материалы, задания, записи, конспекты и
  ссылки к экзамену прошлых лет;
- голоса за полезные ссылки, закрепление одной ссылки и жалобы.

Ссылки привязаны к предмету и учебному полугодию. У физкультуры ссылок нет.

## Кто видит ссылку

| Видимость | Кто видит |
|---|---|
| Только я | только автор |
| Поток (например, «ФИЗ ПИИКТ 3.2.1») | студенты именно этого потока предмета |
| Все | все студенты предмета |

Потоки вложены: ссылка для «3» (лекции) видна всему лекционному потоку, для
«3.2» — практической группе, для «3.2.1» — только этой лабораторной
подгруппе. Потоки разных лет не пересекаются, даже если названия совпадают.

## Откуда сервер знает поток

Из расписания, которое приложение загружает на сервер с «Подключением к
ITMO.Widgets»: каждая пара несёт свой поток, и сервер запоминает, в каких
потоках вы учились. Предложить поток можно только из этого списка.

Проверки через ИСУ для ссылок нет: поток берётся из загруженного расписания, и
изменённое приложение могло бы подставить чужой поток. Поэтому ссылки для
потока проходят модерацию так же, как ссылки для всех. Строгая проверка
членства в потоке отложена.

## Модерация

- Пока включена премодерация (по умолчанию да), каждая новая или изменённая
  ссылка для потока или для всех ждёт модератора. Автор видит «на проверке»,
  «отклонена» (с причиной) или «скрыта».
- Другие всегда видят последнюю одобренную версию. Правка опубликованной
  ссылки не видна, пока её не одобрят; расширение «поток → все» тоже.
- Перевод ссылки в «Только я» скрывает её сразу.
- Администратор может выключить премодерацию — тогда ссылки публикуются сразу,
  а очередь на проверке одобряется.
- Жалоба: «Не открывается», «Другой предмет», «Спам», «Другое». Когда
  пожаловались 3 человека или рейтинг упал до −3 (пороги по умолчанию), ссылка
  попадает к модератору.
- Модератор одобряет, отклоняет, скрывает ссылку, скрывает все ссылки автора
  или ограничивает его. Ограничение не мешает личным ссылкам, удалению и
  закреплению.
- По умолчанию не больше 20 новых версий ссылок в сутки.

## Правила для адресов

- Принимается любой HTTPS-адрес. Сервер сам по ссылкам не ходит.
- Одинаковые ссылки разных авторов в общем списке схлопываются в одну — с
  большим рейтингом.
- Ссылка на Google Таблицу даёт действие «Мои баллы» — свой итог из таблицы
  ([зачётка](grades.md)).
- Редактор подсказывает категорию по сайту: таблица — баллы, форма — очередь,
  Telegram или VK — чат и т.п.

## Без «Подключения»

Ссылки хранятся только на телефоне и видны только вам. После включения
«Подключения» они загружаются на сервер как личные при следующем открытии
предмета.
