# Удаление аккаунта

## Что удаляется

Аккаунт ITMO.Widgets появляется на сервере, когда включено «Подключение к
ITMO.Widgets». Удаление касается только его: аккаунт университета ITMO.ID и
данные в My ITMO не затрагиваются.

Данные на телефоне стирает выход из аккаунта или удаление приложения
([вход и аккаунт](account.md#выход)).

## Как попросить удалить

1. В приложении: «Настройки → Подключение к ITMO.Widgets → Удалить аккаунт
   ITMO.Widgets». Пункт виден и при выключенном подключении — аккаунт мог
   остаться с прошлого раза. Он открывает страницу
   [widgets.alllexey.dev/delete-account](https://widgets.alllexey.dev/delete-account).
2. Написать в Telegram или на почту «Удалить аккаунт» и номер ИСУ.
3. Войти в веб-кабинет через «Профиль → Подключить устройство» — так подтверждается,
   что запрос отправил владелец.
4. Выключить «Подключение», иначе приложение создаст аккаунт заново при
   следующем запросе.

Аккаунт удаляется вручную в течение 30 дней; ответ придёт туда, откуда пришёл
запрос.

## Что остаётся после удаления

| Данные | После удаления |
|---|---|
| Профиль: ИСУ, имя, фото, группы | удаляется |
| Друзья, заявки, приватность | удаляются |
| Устройства, токены уведомлений, сессии сайта | удаляются |
| Расписание на сервере, спорт и очереди | удаляются |
| Личные и неопубликованные ссылки и отзывы, голоса | удаляются |
| Опубликованные отзывы | остаются анонимными |
| Ссылки для потока и для всех | остаются с автором «Удалённый пользователь» |
| Жалобы и решения модерации | остаются без привязки к вам |

Опубликованное остаётся от имени отдельного «Удалённого пользователя», чей
номер ничего не говорит о настоящем ИСУ. Остаётся только последняя одобренная
версия: черновики и правки на проверке удаляются.

## Что дальше

Сервер уже умеет удалять аккаунт сам по запросу из приложения — сразу после
свежего входа через ITMO.ID (не старше 10 минут). Приложения пока этим не
пользуются и открывают страницу запроса.
