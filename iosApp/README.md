# iosApp

The iOS client: a SwiftUI shell that hosts the shared Compose Multiplatform
screens from the Kotlin framework `Shared` (`shared/ios`), plus Swift-only
widgets and a notification service extension. Prerequisites, identifiers and
the full build and test guide are in [docs/ios.md](../docs/ios.md); the design
decision is [ADR 0023](../docs/decisions/0023-ios-client.md).

## Layout

- `project.yml`: the XcodeGen spec; the `.xcodeproj` is generated and ignored,
  never committed.
- `Config/`: identifiers, versions and signing switches as xcconfig build
  settings. `Signing.local.xcconfig` is local and ignored.
- `Resources/`: `Info/` plists and per-target entitlements, unsigned and
  `.signed`.
- `Sources/`: the app target `ITMOWidgets`, the only target that links
  `Shared`.
- `Extensions/Widgets/`, `Extensions/NotificationService/`: Swift-only
  extensions, no Kotlin.
- `Shared/`: sources of the app and both extensions. `Strings/*.xcstrings` and
  `Symbols/AppSymbol.swift` are generated by `./gradlew :app:exportAppleStrings`
  and never edited by hand; `Symbols/Brands.xcassets` holds the `custom.*`
  symbol images.
- `Strings/strings_ios*.xml`: copy only iOS shows (Android resource syntax,
  Russian).
- `Tests/UnitTests/`, `Tests/SnapshotTests/` (swift-snapshot-testing,
  references in `__Snapshots__/`), `Tests/UITests/` (XCUITest smoke tests and
  review screenshots).

## Rules

- The app's Run Script builds `Shared` with `./gradlew
  :shared:ios:embedAndSignAppleFrameworkForXcode`.
- System frameworks only; Swift packages are pinned in `project.yml`.
- No team ID, App Group or Keychain group literal in Swift: read `AppGroupID`
  and `KeychainGroup` from the own process's `Bundle.main`.
- `Tests/UnitTests/StableIdentifiersTests.swift` pins every stable identifier;
  add an assertion with each new one.

## Build and test

```bash
scripts/ios/test.sh                     # generate the project, build, unit and snapshot tests
scripts/ios/test.sh --only <Target>/<Class>
scripts/ios/test.sh --record            # re-record snapshot references
scripts/ios/test.sh ui [<Class>...]     # UITests
scripts/ios/screenshots.sh              # review screenshots
scripts/ios/test.sh --cleanup           # remove the simulators it created
```
