# shared/designsystem

## Owns
- `theme/`: `ItmoTheme`, colour schemes and the dynamic seed (material-kolor), extended colours.
- `tokens/`: spacing, shapes, typography, motion and their JSON export; `components/`: the kit (rows, groups,
  sheets, dialogs, buttons, bars, navigation, state, avatar, charts, settings), each with its previews.
- `icons/`: `AppIconResources`, the `AppIcon` -> drawable table; `composeResources/drawable/ic_*.xml`.
- `gesture/`: tab-swipe helpers; `preview/`: `ItmoPreview`, `PreviewAppearance` and preview fixtures.
- `host/` (`androidMain`): `Fragment.itmoComposeView` and `ItmoBottomSheetFragment` for View hosts.
- `tokens/itmo-tokens.json`: the tokens for iOS and Web; `screenshots/`: the kit's baselines.

## Depends on
- `:shared:core` (`implementation`), CMP material3 and Coil compose (`api`), material-kolor, Coil test (previews).
- `androidMain`: Jetpack material3 pinned `strictly` (ADR 0021), fragment-ktx, MDC `compileOnly`; MDC never draws.
- `:shared:testing` only in tests. Never a feature module; `Avatar` loads through the host's `ImageLoader`, so no
  network fetcher here.
- The only module that opts in to the expressive API (Konsist).

## Verify
`scripts/verify.sh shots designsystem` (`--record` after an intended change), then `scripts/verify.sh quick`.

## Hot files
- Every file here: lane L08.
- `tokens/itmo-tokens.json`: generated by `scripts/verify.sh run -- :shared:designsystem:exportDesignTokens`; a host
  test fails while it is stale. Never edited by hand.
- `composeResources/drawable/ic_*.xml`: written by `scripts/icons-fetch.py` from `docs/design/icons.tsv`.
- `screenshots/*.png`: rewritten only by `shots designsystem --record`, never copied from a gallery.
