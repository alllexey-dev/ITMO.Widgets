# shared/backend-client

## Owns
- `commonMain`, package `dev.alllexey.itmowidgets.client`: Core 2.0, the typed client of ITMO.Widgets Backend.
  `BackendClient` with one `*Api` per area package (`users`, `friends`, `sport`, `links`, `reviews`, `device`,
  `app`, `schedule`), `push` (`FcmDecoder`, no client needed), `common` (shared wire types), `http`, `json`, `error`.
- `commonTest`: per area the route cases, request, decode and vendored-fixture tests; `contract/` (conformance,
  `NotMirrored`, `PendingBackendFields`, `WireModels`); `support/` (the mock-engine kit).
- `src/commonTest/resources/contract/`: Backend's fixtures and OpenAPI snapshot, generated by
  `scripts/sync-backend-contract.sh`. Regenerate it, never edit or hand-merge it. `claims/<area>.txt`: one per area.
- `CONTRACT.md`: wire conventions, the area table, the sync procedure, what is not mirrored.

## Depends on
- Ktor client core and content negotiation, kotlinx serialization JSON, coroutines, kotlinx-datetime; Ktor mock
  and okio in tests only.
- No other `:shared:*` module, no MyItmoApi, no Ktor engine artifact (the caller passes it), no `androidMain` or
  `iosMain` code, no publishing plugin. No clock reads, logging or user-visible text.
- Backend first: never invent a field, route, default or enum value; a fixture that does not decode is a question
  for Backend, not a client workaround. `DemoMode` and `BackendGate` are checked by the holders, never here.

## Verify
`scripts/verify.sh run -- :shared:backend-client:testAndroidHostTest :shared:backend-client:compileTestKotlinIosSimulatorArm64`
(`scripts/verify.sh quick` runs the host tests); `scripts/ios/test.sh kn :shared:backend-client` on the simulator;
`scripts/sync-backend-contract.sh --check` after a sync.

## Hot files
- Every file here: lane L19. `build.gradle.kts` with L04 review; catalog entries through L04.
- `src/commonTest/resources/contract/`: written only by `scripts/sync-backend-contract.sh`.
- The test lists in `commonTest` package `contract` (`AllRouteCases`, `WireModels`, `NotMirrored`,
  `PendingBackendFields`): every area change adds its entries; a rebase conflict there keeps both sides' entries.
